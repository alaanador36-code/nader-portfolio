# Nader Elbahnsawy — Portfolio Website

A bilingual personal portfolio for Nader Elbahnsawy, featuring web development, songwriting, singing, and music composition.

## Run locally

Requirements: Node.js 22+ and npm.

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy

This project includes a `vercel.json` build configuration and can be deployed to Vercel by importing the project repository or uploading it through a supported Git workflow. Use the project root (the folder containing `package.json`) as the root directory. The build command is `npm run build`.

## Search engine visibility

The site includes page titles, descriptions, and a permissive `robots.txt`. After deployment, use your real public domain to configure canonical/Open Graph URLs, create a domain-specific sitemap, and verify the site in Google Search Console. Google indexing is not immediate or guaranteed.
